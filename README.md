## What I do

- **Microsoft 365 administration.** I manage the user lifecycle across Entra ID, Exchange Online and Teams, including groups, roles, licences, mailboxes, shared mailboxes and access permissions.

- **Identity and access.** I led an Entra ID identity governance overhaul that reviewed every account, role and group membership, removed dormant accounts with excessive privileges and introduced a least-privilege RBAC model built on security groups, with the findings documented for leadership.

- **Security.** I configure Conditional Access and MFA, monitor Microsoft Defender and Entra ID sign-in alerts and respond to threats with preventive controls such as geofencing policies. I also led an organisation-wide MFA modernisation, moving users from SMS and legacy per-user MFA to Microsoft Authenticator and the modern Authentication Methods policy using Microsoft Graph PowerShell.

- **Automation.** I build PowerShell scripts with Microsoft Graph API and certificate-based authentication that produce monthly identity audit reports covering inactive users, role assignments, disabled accounts and unlicensed users, scheduled through Task Scheduler. I've also built a Power Automate flow that archives emails and their attachments to SharePoint.

- **Email security.** I traced persistent SPF, DKIM and DMARC failures to an external hosting provider and coordinated the fix and added a new-sender warning in Microsoft 365 to help staff spot spoofed messages.

- **Websites.** I built a 25+ page WordPress website for a not-for-profit wellbeing centre from scratch: choosing the hosting, registering the domain, configuring DNS, designing the pages in Elementor and checking colour contrast against WCAG guidelines. I also diagnosed and fixed a plugin conflict outage.

- **Support.** I troubleshoot Windows 10/11, hardware, printers and networking and I'm familiar with ITIL 4, ServiceNow, Intune and Active Directory.

- **Documentation.** I write system documentation, SOPs, change logs and project reports, including an IT Operations Handbook.
